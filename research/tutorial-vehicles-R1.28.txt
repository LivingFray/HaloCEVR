Tutorial:
- Upstream README documents the look-around/mouse workaround.
- Existing RecordLook ran only through InputHandler::UpdateCamera, excluded
  cutscenes and called the weapon-inventory reader (which rejects parenting).
- Now sampled once after UpdatePoses, before recenter. Menus/loading/tracking
  loss/recenter reset history; active physical vehicle seats exclude it.
- LocalBiped validates campaign mode, live biped, datum generation and player
  ownership; the native controlled-unit field must match. No inventory gate.
- Native history pointer 0x6b145c: bits 0x80/up, 0x100/down, 0x200/left,
  0x400/right. Verified mouse update 0x4727ef and script tests 0x47f390.
- Head strokes >=3 degrees; stick threshold 0.4 held >=80ms. Head travel undoes
  virtual yaw, so snap/recenter discontinuities do not create fake head input.
  Native flag clears reset accumulation; no script completion is forced.

Visibility:
- Retail EXE SHA256 is recorded in retail-1.10-profile.json; inspected read-only.
- render_structure_visibility 0x5537c0 is no-argument cdecl. MinHook entry only.
- At 0x553834 the native byte 0x724a45 selects its conservative PVS path after
  normal portal traversal. It copies BSP PVS data and uses the current culling
  frustum for visible clusters, rather than portal-trimmed frusta.
- BSP 0x746f9c: count+0x134, cluster pointer+0x138, PVS pointer+0x14c.
  Current cluster int32 0x7c3348. Row stride=4*((count+31)/32).
- Valid count 1..512; valid cluster/self visibility and readable row required.
  Visible clusters limited to 128: native per-cluster frusta span
  0x7c3390..0x7d0390, stride0x1a0. The native debug branch lacks this guard.
- Enable only during left/right cockpit-eye native draw with live owner and
  setting enabled. Restore the prior byte immediately. All other draws use
  native behavior. Never dereference a negative cluster or oversize PVS row.
- Verify entry RVA0x1537c0/39 bytes FNV1a9cf1b7a7 and branch RVA0x153834/80
  bytes FNV1ae7733d33. These exclude later Chimera polygon-limit patch sites.
- Matched current-eye culling/raster frusta replace R1.27's +20 degree margin.
  Preserve positive ordinary near/far. No change to rendered-chassis motion.
- Hypothesis: conservative PVS avoids portal trimming from relocated eyes.
  The actual runtime cause is not established. Need route/FPS confirmation.
